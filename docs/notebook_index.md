# Source conversion index

The former notebook-facing package has been replaced by maintained Python
modules/configs/scripts. See [README](../README.md), [commands](commands.md),
[model support](model_support.md) and [the complete conversion mapping](python_conversion.csv).

All 35 notebooks and three original Python sources have import-safe `.py`
transcripts under `legacy/`. The byte-exact original files, including notebook
outputs, remain in the ignored local archive. Duplicate and empty sources are
explicitly retained rather than being counted as additional model implementations.
